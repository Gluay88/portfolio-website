### Deploy

yarn run deploy

This builds the site and pushes the `build` folder to the `gh-pages` branch, which GitHub Pages serves as the live site. **Don't delete `gh-pages`**: it holds only the built files, not source code, but the site goes offline without it. Make changes on `main` and redeploy instead of editing `gh-pages` directly.
