# gh-pages: do not delete

This branch is the live site at https://gluay88.github.io/portfolio-website/.
GitHub Pages serves these files, so deleting this branch takes the site offline.

Everything here is generated by `yarn run deploy` on `main`, which builds the site
and replaces this branch's files with the `build` folder. Don't edit this branch
directly: make changes on `main` and redeploy.

(This note lives in `public/README.md` on `main` so every deploy copies it here.)
